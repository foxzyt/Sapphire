Why Choose Sapphire?

Sapphire isn't just another language; it's a philosophy. We believe in providing a powerful, yet intuitive, development experience from the ground up.

High-Performance Core

Sapphire's main interpreter is meticulously crafted in C++ to ensure your applications run with exceptional speed and efficiency, leveraging low-level power.

Batteries Included Ecosystem

Forget dependency hell. Sapphire aims to provide a comprehensive set of built-in functionalities, from UI to networking, so you can focus on building, not configuring.

Clear and Expressive Syntax

Designed for readability and developer ergonomics. Sapphire's syntax is clean, minimizing boilerplate and allowing your logic to shine through effortlessly.

Get to Know the Syntax

Explore various Sapphire code examples, from basic operations and data types to complex UI interactions and system calls. Our syntax is designed to be intuitive and powerful.

basic_syntax.sp 
// Basic variable declaration and arithmetic operations
var a = 20;
var b = 10;
var c = 25.5;

// Mixed-type arithmetic
var result = a - b * c;

print("Result: " + result);

// Boolean logic and type inference
var isTrue = true;
var isFalse = false;
print(isTrue && isFalse);

// String concatenation and Interpolation (f-strings)
var greeting = "Hello";
var target = "World";
print(greeting + ", " + target + "!");
print(f"Or simpler: {greeting}, {target}!");

// Nullish Coalescing (??)
var userInput = nil;
var username = userInput ?? "Guest";
print("Welcome " + username);

// Function declaration with parameters
function calculateArea(length, width) {
    return length * width;
}

// Concise Arrow Functions
var square = (x) => x * x;
print("Square of 5: " + square(5));

// Function returning void
function greet(name) {
    print("Hello, " + name + "!");
}

// Recursive function example (Factorial)
function factorial(n) {
    if (n == 0) {
        return 1;
    }
    return n * factorial(n - 1);
}

// Function call and variable assignment
var roomArea = calculateArea(10.5, 8.0);
print("Room area: " + roomArea);

greet("Sapphire User");

print("Factorial of 5: " + factorial(5));

// Class declaration with methods
class ButtonClass {
    function click() {
        print("Button was clicked!");
    }
}

var myButton = ButtonClass();

// The powerful Native UI Engine (Retained-Mode)
var app = Window({
    "title": "My App",
    "width": 400,
    "height": 300,
    "children": [
        Text({ "text": "Welcome to Sapphire UI!" }),
        Button({ 
            "label": "Click Me!", 
            "onClick": myButton.click 
        })
    ]
});

// Start the Event Loop
while (updateUI()) {
    Render(app);
}

// Working with dynamic arrays (Lists)
var myList = listCreate();
listAppend(myList, "apple");
listAppend(myList, "banana");
listAppend(myList, 123);

// Array spread operator and destructuring
var extendedList = [...myList, "cherry"];
var [first, second] = extendedList;
print("First element: " + first);

// Shorthand properties and Optional Chaining
var name = "Fox";
var score = 999;
var player = { name, score };

print("Player Name: " + player["name"]);
print("Guild: " + (player?.guild?.name ?? "None")); // Safely handles missing properties

Get Started

Ready to write your first Sapphire program? Follow these simple steps to get the compiler running on your machine.

1. Download the Compiler

Head over to our GitHub Releases page and download the latest Windows executable for the Sapphire Compiler.

2. Write your Code

Create a file named main.sp in any text editor and write your first lines of Sapphire code.

3. Run and Pack

Use the command line to run your script with sapphire.exe main.sp or pack it into a standalone executable using our built-in packaging tool.
