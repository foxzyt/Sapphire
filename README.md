This is an EXPERIMENTAL version of Sapphire 1.0.7 (published in devel branch)

Changelog:

	- Implemented new native functions (String Manipulation)
	- Changed the name of array native functions from ListUtil to Array
	- Added grids (just one grid works right now)
	- Added hot reload
	- Added support for MSVC compilers



NOTES: DON'T USE FLEXBOX IN THIS VERSION! As I said, this is an experimental version and flexbox breaks the entire UI, so for
safety, use grids (only ONE)! This is the first preview for version 1.0.7 (so it's: 1.0.7-experimental-a), so there will be new preview
versions for when the flexbox is ready and other things.

REQUIREMENTS: Download the v1.0.7 libraries from the Releases page!
