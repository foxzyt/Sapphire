Math & System Modules

A programming language is only as powerful as its standard library. Sapphire ships with a highly optimized set of core modules directly bound to C++ functions for maximum performance. This page covers two essential native modules: Math and System.

The Math Module

The Math module provides static functions for complex mathematical operations beyond simple arithmetic. All functions are accessed via Math.functionName().

Basic Math Operations

sapphire 
// Power and square root
var p = Math.pow(2, 8);
print("2 to the power of 8 is: " + p);

var sq = Math.sqrt(144);
print("Square root of 144 is: " + sq);

// Rounding: floor (round down) and ceil (round up)
print("Floor of 4.9: " + Math.floor(4.9));
print("Ceil of 4.1: " + Math.ceil(4.1));

// Absolute value
print("Absolute of -5: " + Math.abs(-5));
> 2 to the power of 8 is: 256
> Square root of 144 is: 12
> Floor of 4.9: 4
> Ceil of 4.1: 5
> Absolute of -5: 5

Trigonometry

You can compute sine, cosine, and tangent of angles (in radians).

sapphire 
var angle = 3.14159 / 2;  // PI/2 radians = 90 degrees

print("Sin of PI/2: " + Math.sin(angle));
print("Cos of PI/2: " + Math.cos(angle));
print("Tan of PI/4: " + Math.tan(3.14159 / 4));
> Sin of PI/2: 1.0
> Cos of PI/2: 0.0
> Tan of PI/4: 1.0

Random Numbers

Generate random numbers between 0 and 1 using Math.rand().

sapphire 
// Generate a random number between 0 and 1
var r = Math.rand();
print("Random number: " + r);

// Simulate a dice roll (1 to 6)
var dice = Math.floor(Math.rand() * 6) + 1;
print("Dice roll: " + dice);
> Random number: 0.827364
> Dice roll: 4

The System Module

The System module lets your Sapphire scripts communicate with the Operating System, allowing you to fetch environment variables, execute shell commands, and measure precise time intervals.

sapphire 
// Getting an Environment Variable
var pathVar = System.getEnv("PATH");

if (pathVar != nil) {
    print("PATH variable found!");
}

// Executing a shell command (platform-dependent)
print("Pinging localhost...");
System.exec("ping 127.0.0.1 -n 2");
> PATH variable found!
> Pinging localhost...
> Pinging 127.0.0.1 with 32 bytes of data:
> Reply from 127.0.0.1: bytes=32 time<1ms TTL=128

High-Resolution Timers

When measuring performance or creating animations, you need a very precise timer. Sapphire offers a millisecond-precision clock via the System.clock() function.

sapphire 
var start = System.clock();

var i = 0;
while (i < 100000) {
    i = i + 1;
}

var end = System.clock();
var diff = end - start;
print("Counted to 100k in: " + diff + " seconds.");
> Counted to 100k in: 0.002 seconds.
