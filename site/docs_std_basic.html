Math & System Modules

A programming language is only as powerful as its standard library. Sapphire ships with a highly optimized set of core modules directly bound to C++ functions for maximum performance. This page covers two essential native modules: Math and System.

The Math Module

The Math module provides static functions for complex mathematical operations beyond simple arithmetic.

sapphire 
// Basic Math operations
var p = pow(2, 8);
print("2 to the power of 8 is: " + p);

var sq = sqrt(144);
print("Square root of 144 is: " + sq);

// Rounding
print("Floor of 4.9: " + floor(4.9));
print("Ceil of 4.1: " + ceil(4.1));
> 2 to the power of 8 is: 256
> Square root of 144 is: 12
> Floor of 4.9: 4
> Ceil of 4.1: 5

Trigonometry and Randomness

You can also compute sine, cosine, tangent, and generate random numbers.

sapphire 
var s = sin(3.14159 / 2);
print("Sin of PI/2 is: " + s);

// Generate a random number between 0 and 1
var r = rand();
print("Random seed: " + r);
> Sin of PI/2 is: 1.0
> Random seed: 0.827364

The System Module

The System module lets your Sapphire scripts communicate with the Operating System, allowing you to fetch environment variables, execute shell commands, and measure precise time intervals.

sapphire 
// Getting an Environment Variable
var pathVar = getEnv("PATH");

if (pathVar != nil) {
    print("PATH variable found!");
}

// Executing a shell command
print("Pinging localhost...");
exec("ping 127.0.0.1 -n 2");
> PATH variable found!
> Pinging localhost...
> Pinging 127.0.0.1 with 32 bytes of data:
> Reply from 127.0.0.1: bytes=32 time<1ms TTL=128

High-Resolution Timers

When measuring performance or creating animations, you need a very precise timer. Sapphire offers a millisecond-precision clock via the System module.

sapphire 
var start = clock();

var i = 0;
while (i < 100000) {
    i = i + 1;
}

var end = clock();
var diff = end - start;
print("Counted to 100k in: " + diff + " seconds.");
> Counted to 100k in: 0.002 seconds.
