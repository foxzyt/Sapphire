Asynchronous Programming

Modern applications frequently perform tasks that take an unknown amount of time: downloading a file, reading a large database, or waiting for a user input. If you block the main execution thread while waiting for these tasks, your application will freeze. Sapphire solves this beautifully with Coroutines and the async / await pattern.

Defining Async Functions

By prepending the async keyword to a function, you tell the Virtual Machine that this function might pause its execution at some point. When an async function is called, it returns a Promise instead of the actual return value.

sapphire 
async function fetchData() {
    print("Fetching data from server...");
    // System.sleep pauses ONLY this coroutine, not the whole app!
    System.sleep(2000); 
    return "Server Response: Status 200 OK";
}

// This will print out that it is a Promise object
var myPromise = fetchData();
print(myPromise);
> Fetching data from server...
> <Promise Object>

Using Await

To actually get the result out of a Promise, you must use the await keyword. This tells Sapphire to yield control back to the event loop, letting other parts of the application run, until the Promise is resolved.

sapphire 
async function main() {
    print("Starting main process...");
    
    // The code waits here for 2 seconds without freezing the app
    var result = await fetchData();
    
    print("Received: " + result);
}

main();
> Starting main process...
> Fetching data from server...
> Received: Server Response: Status 200 OK

Error Handling in Async

If an asynchronous function encounters an error, the Promise is "rejected". You can safely handle rejected Promises using the standard try / catch block around the await call!

sapphire 
async function failingTask() {
    System.sleep(1000);
    throw "Network Disconnected!";
}

async function testError() {
    try {
        await failingTask();
    } catch (err) {
        print("Caught Async Error: " + err);
    }
}

testError();
> Caught Async Error: Network Disconnected!
