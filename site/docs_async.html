Asynchronous Programming

📖 What You Will Learn in This Chapter:
  • What asynchronous programming is and why it prevents freezing
  • How to define async functions with the async keyword
  • How to await promises to get results without blocking
  • How the event loop lets multiple tasks run concurrently
  • How to handle errors in async functions with try/catch

Modern applications frequently perform tasks that take an unknown amount of time: downloading a file, reading a large database, or waiting for a user input. If you block the main execution thread while waiting for these tasks, your application will freeze. Sapphire solves this beautifully with Coroutines and the async / await pattern.

What Is Asynchronous Programming?

In traditional (synchronous) programming, each line of code waits for the previous one to finish. If you call a function that takes 5 seconds, your entire program freezes for 5 seconds.

Asynchronous programming allows your program to start a long-running task, move on to do other things while waiting, and come back to the result when it's ready. Think of it like ordering food at a restaurant: instead of standing at the counter staring at the chef (blocking), you sit down, read a book, and the waiter brings you the food when it's ready (non-blocking).

Defining Async Functions

By prepending the async keyword to a function, you tell the Virtual Machine that this function might pause its execution at some point. When an async function is called, it returns a Promise instead of the actual return value. The function doesn't start executing until the event loop picks it up.

sapphire 
// An async function returns a Promise immediately
async function fetchData() {
    print("Fetching data from server...");
    // System.sleep pauses ONLY this coroutine, not the whole app!
    System.sleep(2000);
    return "Server Response: Status 200 OK";
}

// Calling an async function returns a Promise object
var myPromise = fetchData();
print(myPromise);
> Fetching data from server...
>
💡 Key Insight: The async function starts running immediately when called, but the print("Fetching data...") runs before the System.sleep pauses it. The function will resume later to return the result.

The Event Loop

Sapphire uses an event loop to manage async functions. When an async function calls await (or System.sleep), it yields control back to the event loop, which then runs other tasks that are waiting. This allows multiple async functions to make progress concurrently without using multiple threads.

sapphire 
async function yield_point() {
    return 0; // Async function returns immediately, wrapping in promise.
}

async function taskA() {
    print("A 1");
    await yield_point();
    print("A 2");
    await yield_point();
    print("A 3");
    return "A done";
}

async function taskB() {
    print("B 1");
    await yield_point();
    print("B 2");
    await yield_point();
    print("B 3");
    return "B done";
}

var p1 = taskA();
var p2 = taskB();

print("Main script ending. Event loop should take over!");
> A 1
> B 1
> Main script ending. Event loop should take over!
> A 2
> B 2
> A 3
> B 3

Notice how taskA and taskB interleave their execution. After taskA prints "A 1" and yields, taskB runs and prints "B 1". Then they alternate. This is the power of the event loop!

Using Await

To actually get the result out of a Promise, you must use the await keyword. This tells Sapphire to yield control back to the event loop, letting other parts of the application run, until the Promise is resolved. You can only use await inside an async function.

sapphire 
async function main() {
    print("Starting main process...");

    // The code waits here for 2 seconds without freezing the app
    var result = await fetchData();

    print("Received: " + result);
}

main();
> Starting main process...
> Fetching data from server...
> Received: Server Response: Status 200 OK

Error Handling in Async

If an asynchronous function encounters an error, the Promise is "rejected". You can safely handle rejected Promises using the standard try / catch block around the await call. This works exactly like synchronous exception handling.

sapphire 
async function failingTask() {
    System.sleep(1000);
    throw "Network Disconnected!";
}

async function testError() {
    try {
        await failingTask();
    } catch (err) {
        print("Caught Async Error: " + err);
    }
}

testError();
> Caught Async Error: Network Disconnected!

Overview — What You Learned

✅ Chapter Summary:
  • Asynchronous programming prevents your app from freezing during long operations
  • async function defines a function that can pause and resume: async function foo() { ... }
  • await pauses the async function until a Promise resolves: var result = await someAsync()
  • The event loop automatically interleaves multiple async functions, giving them all a chance to run
  • System.sleep(milliseconds) pauses only the current coroutine, not the whole application
  • try/catch works with await to handle errors in async code
  • Async is ideal for I/O-bound tasks like network requests, file operations, and timers
