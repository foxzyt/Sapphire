File I/O (Input / Output)

Every useful application needs to save data persistently, whether it is user preferences, save states, or system logs. Sapphire provides simple, synchronous methods for interacting with the local filesystem.

Reading Files

Reading a text file is incredibly straightforward. Use readFile() to pull the entire contents of a file into a single string.

sapphire 
try {
    // Attempt to read the file relative to the script's location
    var content = readFile("config.json");
    print("File Contents:");
    print(content);
} catch (err) {
    print("Failed to read file! " + err);
}
> File Contents:
> { "theme": "dark", "version": "1.0.6" }

Writing to Files

You can write strings directly to the filesystem using writeFile(). If the file does not exist, Sapphire will create it. If it does exist, it will overwrite the file completely. If you only want to append text to the end, use appendFile() instead.

sapphire 
var myLog = "Log Entry: User logged in at 10:42 AM\n";

// Overwrites the file
writeFile("server.log", myLog);

// Appends without deleting previous data
appendFile("server.log", "Log Entry: User clicked the button.\n");

print("Logs saved successfully!");
> Logs saved successfully!

Checking if a File Exists

To avoid crashing when attempting to read a missing file, you can verify its existence first using exists().

sapphire 
var path = "C:/windows/system32/cmd.exe";

if (exists(path)) {
    print("The file exists! It is safe to use.");
} else {
    print("File not found.");
}
> The file exists! It is safe to use.
