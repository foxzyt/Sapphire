Native UI Engine

One of Sapphire's most powerful features is its built-in, native User Interface Engine. Unlike other scripting languages that require heavy dependencies like Electron or QT, Sapphire ships with a lightning-fast, retained-mode GUI system right out of the box, bound directly to C++ graphics rendering.

Retained Mode Architecture

Sapphire's UI uses a declarative, "retained-mode" architecture. You describe what the window should look like using a tree of widgets (Windows, Texts, Buttons), and the engine handles drawing and state persistence behind the scenes!

sapphire 
// A simple callback function for our button
function onButtonClick() {
    print("The button was clicked!");
}

// Define the UI Tree using Maps for configuration
var app = Window({
    "title": "My First Sapphire App",
    "width": 400,
    "height": 300,
    "children": [
        Text({ "text": "Welcome to the GUI!" }),
        Button({ 
            "label": "Click Me!", 
            "onClick": onButtonClick 
        })
    ]
});

// Start the Event Loop
// updateUI() returns true as long as the window is open
while (updateUI()) {
    Render(app);
}

Interactive Widgets: The Slider

Because Sapphire manages state across frames (retained-mode), widgets like Sliders maintain their values automatically. You simply bind an onChange event to react to the new value.

sapphire 
var globalVolume = 50;

function onVolumeChange(newValue) {
    globalVolume = newValue;
    print("Volume changed to: " + globalVolume);
}

var settingsApp = Window({
    "title": "Settings",
    "children": [
        Text({ "text": "Adjust Volume:" }),
        Slider({ 
            "min": 0, 
            "max": 100, 
            "initialValue": 50,
            "onChange": onVolumeChange 
        })
    ]
});

while (updateUI()) {
    Render(settingsApp);
}

Building Standalone Executables

Once you finish your UI application, you can pack it into a standalone executable using the spack.exe tool. If your application is pure GUI, you can pass the --no-console flag to hide the black terminal window entirely, resulting in a beautiful, professional desktop application.

bash 
# Compile script to bytecode
sapphirec.exe my_app.sp my_app.sbc

# Pack bytecode into executable, hiding the terminal!
spack.exe my_app.sbc --no-console
