Native UI Engine

One of Sapphire's most powerful features is its built-in, native User Interface Engine. Unlike other scripting languages that require heavy dependencies like Electron or QT, Sapphire ships with a lightning-fast, retained-mode GUI system right out of the box, bound directly to C++ graphics rendering.

Sapphire utilizes modern declarative UI principles and named arguments to construct the UI tree in a way that is highly readable and manageable.

Creating Styles

Before building components, you can define reusable visual styles using the Style() function. Styles can define colors, borders, fonts, and interaction states (like hover color).

sapphire 
// Defining visual styles using named arguments
Style("DisplayBg", bgColor="#000000", textColor="#ffffff", fontSize=64);
Style("DarkBtn", bgColor="#333333", hoverColor="#4d4d4d", borderRadius=40.0, fontSize=32);
Style("OpBtn", bgColor="#ff9f0a", hoverColor="#ffc266", borderRadius=40.0, fontSize=32);

Building Layouts: The Flex Container

The core building block for layout in Sapphire is the Flex container. It allows you to arrange its children either horizontally (row) or vertically (column), just like CSS Flexbox.

sapphire 
var myLayout = Flex(
    direction="column",
    justify="center",
    align="center",
    gap=15.0,
    style="DisplayBg",
    children=[
        /* Widgets go here... */
    ]
);

UI Elements

Sapphire provides a variety of interactive and static elements that you can inject inside your layouts:

1. Text

The Text element is the foundational typographic component in Sapphire's UI Engine. It leverages the internal FontServer to perform sub-pixel anti-aliasing and intelligent text wrapping. This ensures that strings are rendered crisply on any display scale.

  • size: Determines the point size of the font. Defaults to 24.
  • weight: Can be "light", "regular", "bold", or "black".
  • color: A hex string (e.g., "#ff0000") or a named color.
  • shadow: Adds a drop shadow. Takes an object with offsetX, offsetY, and blur.
  • align: Horizontal alignment: "left", "center", "right".
sapphire
Text(
    "Welcome to Sapphire UI Engine!", 
    size=48, 
    weight="bold", 
    color="#ffffff", 
    align="center",
    shadow={"offsetX": 2, "offsetY": 4, "blur": 10}
)

2. Button

The Button is a primary interactive element. Sapphire implements a sophisticated event-bubbling architecture, meaning the button will visually react to onHover, onMouseDown, and onMouseUp automatically based on its designated style.

  • label: The text displayed inside the button. Automatically centered.
  • style: The visual configuration (colors, borders, padding) to apply.
  • onClick: A function callback invoked when the user clicks and releases inside the bounds.
  • disabled: A boolean to prevent interaction and visually gray out the button.
sapphire
Button(
    label="Submit Data", 
    width=150.0, 
    height=50.0, 
    style="PrimaryAction", 
    onClick=(() => print("Data Submitted!")),
    disabled=false
)

3. Slider

The Slider widget allows users to select a numeric value within a specific continuous or discrete range. It is heavily optimized for smooth scrubbing (dragging), utilizing hardware-accelerated interpolation.

  • min / max: The boundaries of the slider track.
  • initialValue: The starting position of the thumb.
  • step: If provided, the slider snaps to increments of this value.
  • onChange: A callback receiving the new float value whenever the thumb is moved.
sapphire
Slider(
    min=0.0, 
    max=1.0, 
    initialValue=0.5, 
    step=0.1,
    width=300.0, 
    onChange=(function(val) { print("Volume: " + (val*100) + "%"); })
)

4. Input (TextField)

The Input widget handles keyboard interactions. It intercepts keystrokes via OS-level hooks, fully supporting clipboard operations (Ctrl+C, Ctrl+V), cursor blinking, text selection highlighting, and unicode character entry.

  • placeholder: Ghost text shown when the input is empty.
  • passwordMode: If true, masks the characters with asterisks.
  • maxLength: Restricts the total number of characters.
  • onSubmit: Triggered when the user presses Enter.
  • onChange: Triggered on every keystroke.
sapphire
Input(
    placeholder="Enter your secure password...", 
    passwordMode=true,
    maxLength=32,
    width=300.0, 
    height=40.0, 
    onSubmit=authenticateUser
)

5. Checkbox

A Checkbox provides a boolean toggle. It is highly customizable, allowing developers to change the checkmark icon, the border radius of the box, and the animation speed when transitioning between checked and unchecked states.

  • label: The descriptive text placed alongside the box.
  • checked: The current boolean state.
  • onChange: A callback triggered when the state toggles, receiving the new boolean.
sapphire
Checkbox(
    label="I agree to the Terms of Service", 
    checked=false, 
    onChange=(function(state) { appState.termsAccepted = state; })
)

6. Image

The Image element utilizes the underlying OpenGL/DirectX texture pipeline. It automatically decodes PNG, JPG, and BMP files asynchronously to prevent the main thread from stalling. It also supports hardware mipmapping for smooth scaling.

  • src: An absolute or relative path to the image asset.
  • fit: Defines scaling: "cover", "contain", or "fill".
  • borderRadius: Enables circular avatars or rounded corners by masking the texture.
sapphire
Image(
    src="assets/profile_pic.png", 
    width=128.0, 
    height=128.0,
    fit="cover",
    borderRadius=64.0 // Perfect circle
)

7. ProgressBar

The ProgressBar provides indispensable visual feedback for long-running async tasks like file downloads or database migrations. It features built-in smooth tweening so that jumps in progress are elegantly animated rather than instantly snapping.

  • progress: A float value between 0.0 (empty) and 1.0 (full).
  • color: The color of the filled portion.
  • trackColor: The color of the unfilled background track.
  • animated: Set to true to enable an indeterminate loading stripe effect.
sapphire
ProgressBar(
    progress=0.85, 
    color="#00ffcc", 
    trackColor="#222222",
    width=400.0,
    height=20.0,
    animated=false
)

8. Dropdown

A sophisticated Dropdown (Combo-box) menu that handles z-index layers automatically to render its popup menu above all other UI elements. It supports scrollable lists if the options exceed the maximum display height.

  • options: An array of strings representing the selectable items.
  • selected: The string currently displayed in the collapsed box.
  • maxHeight: How tall the expanded menu can grow before enabling a vertical scrollbar.
  • onChange: A callback triggered when a new option is clicked.
sapphire
Dropdown(
    options=["Low Quality", "Medium Quality", "Ultra Quality"], 
    selected="Ultra Quality", 
    maxHeight=200.0,
    onChange=(function(opt) { setGraphicsMode(opt); })
)

Render

The Render function injects a given app layout component into the render tree. It must be called for the layout to be visible on the screen. By default, you'll place this near the end of your UI drawing loop.

var event = Render(myLayout);

Complete Example: The Calculator App Architecture

Putting it all together, here is how you structure a declarative, stateful UI in Sapphire, heavily inspired by modern UI frameworks. This resembles our official Calculator test script:

sapphire 
// State
var currentInput = "0";

// Actions
function handleClear() { currentInput = "0"; }

// Render Loop
function updateUI() {
    var app = Flex(
        direction="column",
        justify="flex-start",
        align="center",
        gap=15.0,
        style="DisplayBg",
        children=[
            // The Display Area
            Flex(
                direction="row",
                justify="center",
                align="center",
                width=350.0,
                height=140.0,
                children=[ Text(currentInput, size=72) ]
            ),
            
            // The Buttons Row
            Flex(
                direction="row", 
                gap=10.0, 
                children=[
                    Button(label="AC", width=80.0, height=80.0, style="DarkBtn", onClick=handleClear),
                    Button(label="/", width=80.0, height=80.0, style="OpBtn", onClick=handleDiv)
                ]
            )
        ]
    );
    
    // Instructs the engine to draw the tree
    var event = Render(app);
    if (event != nil) { event() }
    
    return true;
}

Building Standalone Executables

Once you finish your UI application, you can pack it into a standalone executable using the spack.exe tool. If your application is pure GUI, you can pass the --no-console flag to hide the black terminal window entirely, resulting in a beautiful, professional desktop application.

bash 
# Compile script to bytecode
sapphirec.exe my_app.sp my_app.sbc

# Pack bytecode into executable, hiding the terminal!
spack.exe my_app.sbc --no-console
