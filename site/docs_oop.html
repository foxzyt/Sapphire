Object-Oriented Programming (OOP)

📖 What You Will Learn in This Chapter:
  • What Object-Oriented Programming is and why it matters
  • How to define classes and create objects
  • How to use constructors (init()) to initialize objects
  • How to use inheritance with extends to reuse code
  • How to call parent methods with super
  • How to build a complete real-world OOP project

While Sapphire allows you to write simple procedural scripts, it truly shines when building large applications using Object-Oriented patterns. By grouping related data and functions into classes, your code becomes modular, reusable, and much easier to maintain.

What Is OOP?

Object-Oriented Programming is a way of organizing your code around objects rather than functions. Think of an object as a thing that has:

  • Properties — data about the object (e.g., a player's name, health, level)
  • Methods — actions the object can perform (e.g., a player can take damage, heal, level up)

A class is like a blueprint for creating objects. You define the blueprint once, then create as many objects from it as you need.

Defining Classes

You define a class using the class keyword. Inside a class, you can define methods (functions belonging to the class). To reference properties belonging to the current instance, use the this keyword.

sapphire 
class Animal {
    function speak() {
        print(this.name + " makes a noise.");
    }
}

// Creating an instance by calling the class like a function
var dog = Animal();
dog.name = "Rex";
dog.speak();
> Rex makes a noise.

Notice that we set the name property after creating the object. Sapphire allows you to add properties to an object at any time — you don't need to declare them in advance.

Constructors (Initialization)

Often you want to set up an object's initial state as soon as it is created. You can do this by defining a special method called init(). The Sapphire VM will automatically call init() right after the object is allocated in memory. Any arguments passed to the class constructor are forwarded to init().

sapphire 
class Player {
    function init(playerName, startingHealth) {
        this.name = playerName;
        this.health = startingHealth;
        print("Player created: " + this.name);
    }

    function takeDamage(amount) {
        this.health = this.health - amount;
        print(this.name + " has " + this.health + " HP left.");
    }

    function heal(amount) {
        this.health = this.health + amount;
        print(this.name + " healed to " + this.health + " HP.");
    }
}

// Arguments are passed directly to init()
var p1 = Player("Hero", 100);
p1.takeDamage(25);
p1.heal(10);
> Player created: Hero
> Hero has 75 HP left.
> Hero healed to 85 HP.
💡 Tip: The init() method is optional. If you don't need to set up anything when an object is created, you can omit it entirely.

Inheritance

Sapphire supports single inheritance using the extends keyword. This allows a subclass to inherit all properties and methods from a parent class, saving you from writing duplicate code. You can also override parent methods by defining a method with the same name in the subclass.

To call a method from the parent class inside an overridden method, use the super keyword.

sapphire 
class Animal {
    function speak() {
        print("Animal speaks");
    }

    function move() {
        print("Animal moves");
    }
}

class Dog extends Animal {
    // Override the parent's speak method
    function speak() {
        print("Dog barks");
        // Call the parent's move method using super
        super.move();
    }
}

var animal = Animal();
animal.speak();
animal.move();

print("---");

var dog = Dog();
dog.speak();
dog.move();
> Animal speaks
> Animal moves
> ---
> Dog barks
> Animal moves
💡 Tip: super lets you call the parent class's methods even if you've overridden them in the child. This is useful when you want to extend the parent's behavior rather than replace it entirely.

Real-World Example: Bank Account System

Let's build a complete banking system with inheritance to see how OOP works in practice.

sapphire 
// Base class for all accounts
class BankAccount {
    function init(owner, balance) {
        this.owner = owner;
        this.balance = balance;
    }

    function deposit(amount) {
        this.balance = this.balance + amount;
        print(this.owner + " deposited $" + amount);
    }

    function withdraw(amount) {
        if (this.balance >= amount) {
            this.balance = this.balance - amount;
            print(this.owner + " withdrew $" + amount);
        } else {
            print("Insufficient funds!");
        }
    }

    function displayBalance() {
        print(this.owner + "'s balance: $" + this.balance);
    }
}

// Savings account — adds interest rate
class SavingsAccount extends BankAccount {
    function init(owner, balance, interestRate) {
        super.init(owner, balance);
        this.interestRate = interestRate;
    }

    function applyInterest() {
        var interest = this.balance * (this.interestRate / 100);
        this.balance = this.balance + interest;
        print("Interest applied: $" + interest);
    }
}

// Checking account — adds an overdraft limit
class CheckingAccount extends BankAccount {
    function init(owner, balance, overdraftLimit) {
        super.init(owner, balance);
        this.overdraftLimit = overdraftLimit;
    }

    // Override withdraw to allow overdraft
    function withdraw(amount) {
        if (this.balance + this.overdraftLimit >= amount) {
            this.balance = this.balance - amount;
            print(this.owner + " withdrew $" + amount + " (using overdraft)");
        } else {
            print("Overdraft limit exceeded!");
        }
    }
}

// Test the system
var savings = SavingsAccount("Alice", 1000, 5.0);
savings.deposit(500);
savings.applyInterest();
savings.displayBalance();

print("---");

var checking = CheckingAccount("Bob", 500, 200);
checking.withdraw(600);  // Uses overdraft
checking.withdraw(200);  // Exceeds overdraft limit
checking.displayBalance();
> Alice deposited $500
> Interest applied: $75.0
> Alice's balance: $1575.0
> ---
> Bob withdrew $600 (using overdraft)
> Overdraft limit exceeded!
> Bob's balance: $-100

Overview — What You Learned

✅ Chapter Summary:
  • Classes are blueprints for creating objects using the class keyword
  • Objects are created by calling the class like a function: ClassName()
  • Properties are set with dot notation: object.property = value
  • Methods are functions inside a class that use this to access the current object
  • Constructors are defined with init() and are called automatically when an object is created
  • Inheritance with extends lets a child class reuse code from a parent class
  • super calls the parent class's methods from an overridden method
  • OOP helps organize code into reusable, modular components for larger applications
