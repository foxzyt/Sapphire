Object-Oriented Programming (OOP)

While Sapphire allows you to write simple procedural scripts, it truly shines when building large applications using Object-Oriented patterns. By grouping related data and functions into classes, your code becomes modular, reusable, and much easier to maintain.

Defining Classes

You define a class using the class keyword. Inside a class, you can define methods (functions belonging to the class). To reference properties belonging to the current instance, use the this keyword.

sapphire 
class Animal {
    // A method inside the class
    function speak() {
        print(this.name + " makes a noise.");
    }
}

// Creating an instance by calling the class like a function
var dog = Animal();
dog.name = "Rex";
dog.speak();
> Rex makes a noise.

Constructors (Initialization)

Often you want to set up an object's initial state as soon as it is created. You can do this by defining a special method called init(). The Sapphire VM will automatically call init() right after the object is allocated in memory.

sapphire 
class Player {
    function init(playerName, startingHealth) {
        this.name = playerName;
        this.health = startingHealth;
        print("Player created: " + this.name);
    }

    function takeDamage(amount) {
        this.health = this.health - amount;
        print(this.name + " has " + this.health + " HP left.");
    }
}

// The arguments are passed directly to the init method
var p1 = Player("Hero", 100);
p1.takeDamage(25);
> Player created: Hero
> Hero has 75 HP left.

Inheritance

Sapphire supports single inheritance using the extends keyword. This allows a subclass to inherit all properties and methods from a parent class, saving you from writing duplicate code.

sapphire 
class Vehicle {
    function drive() {
        print("The vehicle is moving.");
    }
}

// Car inherits from Vehicle
class Car extends Vehicle {
    function honk() {
        print("Beep beep!");
    }
}

var myCar = Car();
myCar.drive(); // Inherited method
myCar.honk();  // Subclass specific method
> The vehicle is moving.
> Beep beep!
