HTTP Requests

Connecting to external APIs, downloading resources, or interacting with a backend server are core requirements of any modern programming language. Sapphire ships with an extremely fast HTTP Client module natively backed by libcurl.

Performing a GET Request

The simplest way to interact with the web is by performing a GET request to a URL. The httpGet() method synchronously fetches the URL and returns the raw response body.

sapphire 
print("Fetching JSON placeholder...");

var response = httpGet("https://jsonplaceholder.typicode.com/todos/1");

print("Server Response:");
print(response);
> Fetching JSON placeholder...
> Server Response:
> {
> "userId": 1,
> "id": 1,
> "title": "delectus aut autem",
> "completed": false
> }

Using HTTP with Async

Because HTTP requests are strictly I/O bound and can take several seconds depending on network latency, it is highly recommended to wrap your HTTP calls in an async function and use await or a background Thread so your application (especially the UI) doesn't freeze.

sapphire 
async function downloadData(url) {
    try {
        // Wait for the network...
        var body = await httpGet(url);
        print("Downloaded " + String.length(body) + " bytes successfully!");
    } catch (e) {
        print("Failed to download: " + e);
    }
}

print("Starting download...");
downloadData("https://example.com");
> Starting download...
> Downloaded 1256 bytes successfully!
