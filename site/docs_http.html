1. What Is HTTP? (For Beginners)

HTTP stands for Hypertext Transfer Protocol. It is the language that web browsers and servers use to talk to each other. When you visit a website, your browser sends an HTTP request to a server, and the server sends back an HTTP response (usually HTML, JSON, or an image).

Think of HTTP like ordering at a restaurant:

  • You (the client) look at the menu and decide what you want
  • You tell the waiter your order — that's an HTTP request
  • The kitchen (the server) prepares your food
  • The waiter brings it back to you — that's the HTTP response

Sapphire lets your programs act as HTTP clients, meaning you can send requests to any web server and use the response data in your code.

HTTP Methods

The most common HTTP methods are:

  • GET — Fetch data from a server (like reading a webpage)
  • POST — Send data to a server to create something (like submitting a form)
  • PUT — Update existing data on a server
  • DELETE — Remove data from a server

In Sapphire, you'll primarily use httpGet() for fetching data. The response is always returned as a string.

2. Performing a GET Request

The simplest way to interact with the web is by performing a GET request to a URL. The httpGet() function synchronously fetches the URL and returns the raw response body as a string.

sapphire 
print("Fetching JSON placeholder...");

var response = httpGet("https://jsonplaceholder.typicode.com/todos/1");

print("Server Response:");
print(response);
> Fetching JSON placeholder...
> Server Response:
> {
> "userId": 1,
> "id": 1,
> "title": "delectus aut autem",
> "completed": false
> }
💡 Note: httpGet() is synchronous — it will pause your program until the server responds. For network requests, this could take several seconds. See the next section on how to make it non-blocking with async.

3. Parsing JSON Responses

Most modern APIs return data in JSON format (JavaScript Object Notation). In Sapphire, you can use the jsonParse() function to convert a JSON string into a Sapphire Map that you can work with directly.

sapphire 
var response = httpGet("https://jsonplaceholder.typicode.com/todos/1");

// Parse the JSON string into a Sapphire map
var data = jsonParse(response);

// Now we can access the data using bracket notation
print("Title: " + data["title"]);
print("Completed: " + data["completed"]);
> Title: delectus aut autem
> Completed: false

4. Using HTTP with Async (Recommended)

Because HTTP requests are I/O bound and can take several seconds depending on network latency, it is highly recommended to wrap your HTTP calls in an async function and use await. This way your application (especially the UI) doesn't freeze while waiting for the network.

sapphire 
async function downloadData(url) {
    try {
        // Wait for the network without freezing the app
        var body = await httpGet(url);
        print("Downloaded " + String.length(body) + " bytes successfully!");
        return body;
    } catch (e) {
        print("Failed to download: " + e);
        return nil;
    }
}

print("Starting download...");
downloadData("https://example.com");
> Starting download...
> Downloaded 1256 bytes successfully!

5. Error Handling

Network requests can fail for many reasons: the server might be down, the URL might be wrong, or your internet connection might be lost. Always wrap HTTP calls in try/catch blocks.

sapphire 
function safeFetch(url) {
    try {
        print("Fetching: " + url);
        var result = httpGet(url);
        print("Success! Response length: " + len(result));
        return result;
    } catch (e) {
        print("Error fetching URL: " + e);
        return nil;
    }
}

// Test with a valid URL
var data = safeFetch("https://jsonplaceholder.typicode.com/todos/1");

// Test with an invalid URL
var badData = safeFetch("https://thisdoesnotexist.fake");

if (badData == nil) {
    print("Using cached data instead.");
}
> Fetching: https://jsonplaceholder.typicode.com/todos/1
> Success! Response length: 83
> Fetching: https://thisdoesnotexist.fake
> Error fetching URL: Could not resolve host
> Using cached data instead.

6. Real-World Example: Weather App

Let's build a complete weather application that fetches data from a public API, parses the JSON response, and displays the information in a readable format.

sapphire 
// =========================================
//  WEATHER APP — fetches live weather data
// =========================================

// Note: You need a free API key from openweathermap.org
// Replace "YOUR_API_KEY" with your actual key

var API_KEY = "YOUR_API_KEY";
var CITY = "London";

function getWeather(city) {
    var url = "https://api.openweathermap.org/data/2.5/weather?q=" + city + "&appid=" + API_KEY + "&units=metric";

    try {
        print("Fetching weather for " + city + "...");
        var response = httpGet(url);

        // Parse the JSON response
        var data = jsonParse(response);

        // Check if the API returned an error
        if (data["cod"] != 200) {
            print("Error: " + data["message"]);
            return nil;
        }

        // Extract the data we need
        var main = data["main"];
        var weather = data["weather"][0];
        var wind = data["wind"];

        print("\n=== Weather in " + city + " ===");
        print("Condition: " + weather["description"]);
        print("Temperature: " + main["temp"] + "°C");
        print("Feels like: " + main["feels_like"] + "°C");
        print("Humidity: " + main["humidity"] + "%");
        print("Wind: " + wind["speed"] + " m/s");

        return data;
    } catch (e) {
        print("Failed to get weather: " + e);
        return nil;
    }
}

// Run the function
getWeather(CITY);
> Fetching weather for London...
>
> === Weather in London ===
> Condition: broken clouds
> Temperature: 15.3°C
> Feels like: 14.8°C
> Humidity: 72%
> Wind: 4.5 m/s

7. Real-World Example: Fetching with Async

Here's the same weather app using async/await so it doesn't block the main thread — perfect for use with the UI Engine.

sapphire 
async function fetchWeatherAsync(city) {
    var url = "https://api.openweathermap.org/data/2.5/weather?q=" + city + "&appid=" + API_KEY + "&units=metric";

    try {
        var response = await httpGet(url);
        var data = jsonParse(response);

        if (data["cod"] == 200) {
            print(f"Weather: {data["main"]["temp"]}°C");
        } else {
            print("API Error: " + data["message"]);
        }
    } catch (e) {
        print("Network error: " + e);
    }
}

print("Starting async weather fetch...");
fetchWeatherAsync("Tokyo");
print("Main thread is still free while waiting!");
> Starting async weather fetch...
> Main thread is still free while waiting!
> Weather: 22.1°C

8. Overview — What You Learned

✅ Chapter Summary:
  • HTTP is the protocol used to communicate with web servers
  • httpGet(url) fetches data from a URL and returns it as a string
  • jsonParse(string) converts a JSON response into a Sapphire Map for easy access
  • Always wrap HTTP calls in try/catch to handle network errors gracefully
  • Use async/await with httpGet to prevent your application from freezing
  • Check the response status code (e.g., cod == 200) to verify the request succeeded
  • Real-world APIs like OpenWeatherMap return nested JSON that you can traverse with bracket notation
