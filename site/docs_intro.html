Introduction to Sapphire

Welcome to Sapphire! This tutorial will guide you through the absolute basics of the language. Sapphire was born out of a desire for a language that is as fast as C++, but as easy to write as Python or JavaScript. It features an incredibly clean syntax, an intuitive standard library, and built-in native UI rendering capabilities.

Whether you are building command-line tools, high-performance background services, or desktop applications with graphical interfaces, Sapphire has you covered.

Hello, World!

Every journey begins with a single step. In Sapphire, outputting text to the console is done using the built-in print() function. It automatically appends a newline at the end, so you don't have to worry about formatting it manually.

sapphire 
print("Hello, World!");
> Hello, World!

You can also print multiple arguments by concatenating them with the + operator. Since Sapphire dynamically resolves types for standard output, concatenating strings and numbers is completely safe!

String Interpolation (f-strings)

For a cleaner way to format strings with variables, you can use f-strings (added in v1.0.9). Simply prefix the string with f and use curly braces {} to insert variables or expressions directly.

sapphire 
var name = "Developer";
print(f"Welcome, {name}!");

Variables and Data Types

Sapphire is a dynamically typed language. This means you do not have to declare the type of a variable (like int, string, or bool). Instead, you simply use the var keyword, and the VM figures out the rest!

sapphire 
// Using 'var' to declare variables
var name = "Sapphire";
var version = 1.0;
var isAwesome = true;

print(name + " version " + version + " is awesome: " + isAwesome);
> Sapphire version 1.0 is awesome: true

Reassignment and Dynamic Types

Because variables are dynamically typed, you can reassign a variable to a completely different type later in your code without causing a compiler error. The Sapphire Virtual Machine handles the memory reallocation safely.

sapphire 
var data = 42;
print("Data is a number: " + data);

// Reassigning to a string
data = "Now I am a string!";
print("Data changed: " + data);
> Data is a number: 42
> Data changed: Now I am a string!

Basic Arithmetic

Sapphire supports all standard mathematical operators: addition (+), subtraction (-), multiplication (*), division (/), and modulo (%). The language follows standard mathematical precedence rules (PEMDAS).

sapphire 
var a = 10;
var b = 3;

print("Addition: " + (a + b));
print("Division: " + (a / b));
print("Modulo: " + (a % b));

// Complex expressions
var complex = (a * b) + (100 / 2);
print("Complex Result: " + complex);
> Addition: 13
> Division: 3.333333
> Modulo: 1
> Complex Result: 80

Nullish Coalescing & Optional Chaining

When working with variables that might be nil (null), Sapphire v1.0.9 introduced two powerful operators:

  • ?? (Nullish Coalescing): Returns the right side if the left side is nil. Useful for default values.
  • ?. (Optional Chaining): Safely accesses properties or methods. If the object is nil, the expression short-circuits and returns nil instead of throwing an error.
sapphire 
var input = nil;
var username = input ?? "Guest";
print(username); // Prints: Guest

var user = nil;
print(user?.profile?.email); // Safely prints nil
