SQLite Database

1. What Is SQLite? (For Beginners)

SQLite is a database engine — a piece of software that lets you store, organize, and retrieve data on your computer without needing a separate server or a database administrator. When you hear about "databases" like MySQL, PostgreSQL, or SQL Server, those are server-based databases: you install a server program, it runs in the background, and your application talks to it over the network.

SQLite is different. It is serverless and embedded. The entire database is just a single file on your hard drive (for example, myapp.db). Your program reads and writes directly to that file, no server required. This makes SQLite the most widely deployed database engine in the world — it's in every smartphone, every browser, many game consoles, and Sapphire itself!

text 
SQLite vs Server-Based Databases (MySQL, PostgreSQL):

┌─────────────────────────────────────────────────────────────────────┐
│  SQLite                          │  MySQL / PostgreSQL             │
├─────────────────────────────────────────────────────────────────────┤
│  Single file (e.g. data.db)      │  Multiple files, server process │
│  No setup, no passwords          │  Requires installation & config │
│  Great for small/medium apps     │  Built for large-scale apps     │
│  Perfect for local storage       │  Designed for network access    │
│  Embedded in your program        │  Runs as a separate service     │
└─────────────────────────────────────────────────────────────────────┘

In Sapphire, SQLite is built-in. You don't need to install anything extra. Just create a SQLite object and start using it.

2. How Databases Work — A Simple Analogy

Imagine you have a filing cabinet in your office. Inside the cabinet, you have several folders. Inside each folder, you have sheets of paper with information written in rows and columns.

  • Database = the entire filing cabinet (the .db file)
  • Table = a specific folder in the cabinet (e.g., "Customers", "Orders")
  • Row = a single sheet of paper in that folder (a single record)
  • Column = a specific field on every sheet (e.g., "Name", "Email")

When you ask SQLite a question like "find all customers named Alice", it's like opening the "Customers" folder, scanning every sheet, and pulling out only the ones where the Name field says "Alice". SQLite does this incredibly fast, even with thousands or millions of records.

text 
Filing Cabinet (Database)           SQLite Table
─────────────────────────────────────────────────────
Cabinet      → database.db file
Folder       → "users" table
Sheet        → one row (one user)
Column       → name, email, age
Tab label    → PRIMARY KEY (unique ID)

3. Creating and Connecting to a Database

To work with SQLite in Sapphire, you first create a SQLite instance, then call open() with a filename. If the file doesn't exist, SQLite creates it automatically. You can also use the special name ":memory:" to create a database that lives only in RAM (it disappears when your program ends).

sapphire 
// Create a SQLite instance
var sql = SQLite();

// Open a file-based database (creates 'shop.db' if it doesn't exist)
var db = sql.open("shop.db");

// Check if it worked
if (db == -1) {
    print("Failed to open database!");
} else {
    print("Database connected successfully!");
}
> Database connected successfully!
sapphire 
// In-memory database — fast, temporary, perfect for testing
var sql = SQLite();
var db = sql.open(":memory:");
print("In-memory database created!");
> In-memory database created!
sapphire 
// Alternative: object-style API (no manual db handle)
var sqlite = SQLite();
sqlite.open(":memory:");

// Now you can call execute/query directly on the object
sqlite.execute("CREATE TABLE test (id INTEGER, value TEXT)");
print("Table created via object-style API!");
> Table created via object-style API!
sapphire 
// Always close the database when you're done!
sql.close(db);
print("Database closed.");
> Database closed.
💡 Tip: Use ":memory:" while you're developing and testing. Once you're ready to save data permanently, switch to a file name like "myapp.db".

4. Understanding Tables — The Heart of SQL

A table is where your data actually lives. Think of it like a spreadsheet: it has columns (the categories of information) and rows (the actual data entries). You define the structure of a table with the CREATE TABLE SQL statement.

sql 
-- This is how you think about a table visually:

-- TABLE: users
-- ┌────┬──────────┬──────────┬───────┐
-- │ id │ username  │ email    │  age  │  ← column names
-- ├────┼──────────┼──────────┼───────┤
-- │ 1  │ alice    │ a@x.com  │  30   │  ← one row
-- │ 2  │ bob      │ b@x.com  │  25   │  ← another row
-- │ 3  │ carol    │ c@x.com  │  28   │  ← another row
-- └────┴──────────┴──────────┴───────┘

Here's how you create that table in Sapphire:

sapphire 
var sql = SQLite();
var db = sql.open(":memory:");

// Create a table with columns: id, username, email, age
sql.execute(db, "CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    username TEXT,
    email TEXT,
    age INTEGER
)");

print("Table 'users' created!");
> Table 'users' created!

4.1 What Does INTEGER PRIMARY KEY Mean?

PRIMARY KEY is a special marker that tells SQLite: "this column uniquely identifies each row." No two rows can have the same value in this column. When you combine INTEGER PRIMARY KEY with SQLite, it becomes auto-incrementing — SQLite automatically assigns the next available number (1, 2, 3, ...) if you don't provide one.

sapphire 
// The PRIMARY KEY auto-increments — we don't specify 'id'
sql.execute(db, "INSERT INTO users (username, email, age) VALUES ('alice', 'a@x.com', 30)");
sql.execute(db, "INSERT INTO users (username, email, age) VALUES ('bob', 'b@x.com', 25)");

var rows = sql.query(db, "SELECT * FROM users");
for (var row of rows) {
    print("ID: " + row.id + " | Username: " + row.username);
}
> ID: 1 | Username: alice
> ID: 2 | Username: bob
💡 Tip: Always use INTEGER PRIMARY KEY for your ID columns. It makes your life easier because SQLite handles the numbering for you.

4.2 The IF NOT EXISTS Safety Net

If you run CREATE TABLE twice on the same table, SQLite will throw an error. To avoid this, always add IF NOT EXISTS — it tells SQLite: "only create this table if it doesn't already exist."

sapphire 
// Safe — runs only once, ignores subsequent calls
sql.execute(db, "CREATE TABLE IF NOT EXISTS products (
    id INTEGER PRIMARY KEY,
    name TEXT,
    price REAL
)");

print("Table created (or already existed).");
> Table created (or already existed).

4.3 Dropping a Table

To remove a table entirely (including all its data), use DROP TABLE. Be careful — this is permanent!

sapphire 
sql.execute(db, "DROP TABLE IF EXISTS products");
print("Table 'products' deleted.");
> Table 'products' deleted.

5. CRUD Operations (Create, Read, Update, Delete)

In any database application, you'll perform four basic operations, often called CRUD:

  • Create — INSERT new records
  • Read — SELECT (query) existing records
  • Update — UPDATE existing records
  • Delete — DELETE records

Let's build a complete example that demonstrates all four operations.

5.1 Create (INSERT)

sapphire 
var sql = SQLite();
var db = sql.open(":memory:");

sql.execute(db, "CREATE TABLE IF NOT EXISTS products (
    id INTEGER PRIMARY KEY,
    name TEXT,
    price REAL,
    quantity INTEGER
)");

// INSERT single row
sql.execute(db, "INSERT INTO products (name, price, quantity) VALUES ('Laptop', 999.99, 10)");

// INSERT multiple rows
sql.execute(db, "INSERT INTO products (name, price, quantity) VALUES ('Mouse', 29.99, 50)");
sql.execute(db, "INSERT INTO products (name, price, quantity) VALUES ('Keyboard', 79.99, 30)");

print("3 products inserted!");
> 3 products inserted!

5.2 Read (SELECT)

sapphire 
// Select all products
var allProducts = sql.query(db, "SELECT * FROM products");

print("--- All Products ---");
for (var p of allProducts) {
    print(p.id + ". " + p.name + " - $" + p.price + " (Qty: " + p.quantity + ")");
}
> --- All Products ---
> 1. Laptop - $999.99 (Qty: 10)
> 2. Mouse - $29.99 (Qty: 50)
> 3. Keyboard - $79.99 (Qty: 30)

5.3 Update (UPDATE)

sapphire 
// Update the price of the Laptop
sql.execute(db, "UPDATE products SET price = 899.99 WHERE name = 'Laptop'");

// Verify the update
var laptop = sql.query(db, "SELECT * FROM products WHERE name = 'Laptop'");
print("Updated: " + laptop[0].name + " now costs $" + laptop[0].price);
> Updated: Laptop now costs $899.99
⚠️ Warning: If you run UPDATE products SET price = 0 without a WHERE clause, it will update every row in the table! Always double-check your WHERE clause before running an UPDATE.

5.4 Delete (DELETE)

sapphire 
// Delete the Mouse product
sql.execute(db, "DELETE FROM products WHERE name = 'Mouse'");

// Verify — only 2 products remain
var remaining = sql.query(db, "SELECT * FROM products");
print("Remaining products: " + len(remaining));
> Remaining products: 2
⚠️ Warning: Same as UPDATE — DELETE FROM products without a WHERE clause deletes everything in the table!

5.5 Complete CRUD Example

sapphire 
function crudDemo() {
    var sql = SQLite();
    var db = sql.open(":memory:");

    // --- CREATE ---
    sql.execute(db, "CREATE TABLE IF NOT EXISTS tasks (
        id INTEGER PRIMARY KEY,
        title TEXT,
        done INTEGER DEFAULT 0
    )");

    sql.execute(db, "INSERT INTO tasks (title) VALUES ('Buy groceries')");
    sql.execute(db, "INSERT INTO tasks (title) VALUES ('Read a book')");
    sql.execute(db, "INSERT INTO tasks (title) VALUES ('Write code')");
    print("Created 3 tasks.");

    // --- READ ---
    var tasks = sql.query(db, "SELECT * FROM tasks");
    print("\n--- All Tasks ---");
    for (var t of tasks) {
        print(t.id + ". " + t.title + " [done: " + t.done + "]");
    }

    // --- UPDATE ---
    sql.execute(db, "UPDATE tasks SET done = 1 WHERE title = 'Buy groceries'");
    print("\nMarked 'Buy groceries' as done.");

    // --- DELETE ---
    sql.execute(db, "DELETE FROM tasks WHERE done = 1");
    print("Deleted completed tasks.\n");

    // --- FINAL STATE ---
    var finalTasks = sql.query(db, "SELECT * FROM tasks");
    print("--- Remaining Tasks ---");
    for (var t of finalTasks) {
        print(t.id + ". " + t.title);
    }

    sql.close(db);
}

crudDemo();

>
> --- All Tasks ---
> 1. Buy groceries [done: 0]
> 2. Read a book [done: 0]
> 3. Write code [done: 0]
>
> Marked 'Buy groceries' as done.
> Deleted completed tasks.
>
> --- Remaining Tasks ---
> 2. Read a book
> 3. Write code

6. Selecting Data — The SELECT Statement

SELECT is how you read data from a table. It's the most commonly used SQL command. The basic structure is:

sql 
SELECT column1, column2, ... FROM table_name WHERE condition ORDER BY column;

6.1 Selecting Specific Columns

sapphire 
// Instead of SELECT *, pick only the columns you need
var names = sql.query(db, "SELECT name, price FROM products");

for (var item of names) {
    print(item.name + " costs $" + item.price);
}
> Laptop costs $899.99
> Keyboard costs $79.99

6.2 Ordering Results

sapphire 
// Sort by price from lowest to highest (ASC = ascending)
var cheapest = sql.query(db, "SELECT * FROM products ORDER BY price ASC");
print("Cheapest first:");
for (var p of cheapest) {
    print("  $" + p.price + " - " + p.name);
}

// Sort by price from highest to lowest (DESC = descending)
var expensive = sql.query(db, "SELECT * FROM products ORDER BY price DESC");
print("Most expensive first:");
for (var p of expensive) {
    print("  $" + p.price + " - " + p.name);
}
> Cheapest first:
> $79.99 - Keyboard
> $899.99 - Laptop
> Most expensive first:
> $899.99 - Laptop
> $79.99 - Keyboard

6.3 Limiting Results

sapphire 
// Get only the top 2 cheapest products
var top2 = sql.query(db, "SELECT * FROM products ORDER BY price ASC LIMIT 2");
print("Top 2 cheapest:");
for (var p of top2) {
    print("  " + p.name + " - $" + p.price);
}
> Top 2 cheapest:
> Keyboard - $79.99
> Laptop - $899.99

6.4 Counting Rows

sapphire 
// COUNT returns the number of rows matching the query
var countResult = sql.query(db, "SELECT COUNT(*) as total FROM products");
print("Total products: " + countResult[0].total);

// You can also use it with WHERE
var cheapCount = sql.query(db, "SELECT COUNT(*) as cnt FROM products WHERE price < 100");
print("Products under $100: " + cheapCount[0].cnt);
> Total products: 2
> Products under $100: 1

7. Filtering Data with WHERE

The WHERE clause is how you filter data. It's like saying "only give me the rows that match this condition." You can combine conditions with AND and OR.

7.1 Comparison Operators

sql 
-- Common operators you can use in WHERE:
--   =    equal to
--   !=   not equal to
--   >    greater than
--   <    less than
--   >=   greater than or equal
--   <=   less than or equal
--   LIKE pattern matching (% = wildcard)
--   IN    check if value is in a list
sapphire 
// Equal to
var result = sql.query(db, "SELECT * FROM products WHERE name = 'Laptop'");

// Greater than
var expensive = sql.query(db, "SELECT * FROM products WHERE price > 100");

// AND — both conditions must be true
var specific = sql.query(db, "SELECT * FROM products WHERE price > 50 AND quantity > 20");

// OR — at least one condition must be true
var either = sql.query(db, "SELECT * FROM products WHERE name = 'Laptop' OR name = 'Mouse'");

// LIKE — pattern matching (% matches any characters)
var startsWithK = sql.query(db, "SELECT * FROM products WHERE name LIKE 'K%'");
print("Products starting with 'K': " + len(startsWithK));

// IN — check if value is in a list
var inList = sql.query(db, "SELECT * FROM products WHERE name IN ('Laptop', 'Mouse')");
> Products starting with 'K': 1

7.2 WHERE with NULL

sapphire 
// Insert a product with no quantity specified
sql.execute(db, "INSERT INTO products (name, price) VALUES ('Headphones', 149.99)");

// Find products where quantity is NULL (was never set)
var nullQty = sql.query(db, "SELECT * FROM products WHERE quantity IS NULL");
print("Products with NULL quantity:");
for (var p of nullQty) {
    print("  " + p.name);
}

// NOT NULL — find products that DO have a quantity
var hasQty = sql.query(db, "SELECT * FROM products WHERE quantity IS NOT NULL");
print("Products with quantity set: " + len(hasQty));
> Products with NULL quantity:
> Headphones
> Products with quantity set: 2
⚠️ Important: In SQL, NULL is not the same as 0 or an empty string. NULL means "unknown" or "not set." You cannot use = NULL — you must use IS NULL or IS NOT NULL.

8. SQLite Data Types

SQLite uses a flexible type system. Unlike other databases that enforce strict typing, SQLite will try to store whatever value you give it. But it's best to use the right type for each column. Here are the main types:

sql 
-- SQLite Data Types

-- INTEGER: Whole numbers (no decimal point)
--   Examples: 0, 1, 42, -7, 999999
CREATE TABLE example_integers (id INTEGER, age INTEGER, count INTEGER);

-- REAL: Decimal numbers (floating point)
--   Examples: 3.14, 99.99, -0.5, 1.0
CREATE TABLE example_reals (id INTEGER, price REAL, rating REAL);

-- TEXT: Strings of characters
--   Examples: 'hello', 'Alice', '2024-01-15', 'user@email.com'
CREATE TABLE example_texts (id INTEGER, name TEXT, email TEXT);

-- BLOB: Binary data (images, files, etc.)
--   Usually not needed for beginners
CREATE TABLE example_blobs (id INTEGER, image BLOB);

-- NULL: Represents "no value" or "unknown"
--   Any column can be NULL unless you say NOT NULL
sapphire 
// A practical example using all common types
sql.execute(db, "CREATE TABLE IF NOT EXISTS employees (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    salary REAL,
    department TEXT,
    is_active INTEGER,   -- 1 = true, 0 = false
    joined_date TEXT     -- store dates as TEXT in YYYY-MM-DD format
)");

sql.execute(db, "INSERT INTO employees VALUES (1, 'Alice', 75000.50, 'Engineering', 1, '2023-01-15')");
sql.execute(db, "INSERT INTO employees VALUES (2, 'Bob', 62000.00, 'Marketing', 1, '2023-06-01')");
sql.execute(db, "INSERT INTO employees VALUES (3, 'Carol', 82000.00, 'Engineering', 0, '2022-03-20')");

var emps = sql.query(db, "SELECT * FROM employees");
for (var e of emps) {
    print(e.name + " | $" + e.salary + " | " + e.department + " | Active: " + e.is_active);
}
> Alice | $75000.5 | Engineering | Active: 1
> Bob | $62000 | Marketing | Active: 1
> Carol | $82000 | Engineering | Active: 0
💡 Tip: For boolean values (true/false), use INTEGER with 0 for false and 1 for true. For dates, store them as TEXT in the format YYYY-MM-DD — this allows sorting and comparison to work correctly.

9. Multiple Tables & Relationships

Real applications rarely use a single table. Most of the time, you'll have multiple related tables. For example, a blog might have a users table and a posts table, where each post belongs to a user. This is called a relationship.

sql 
-- THE RELATIONSHIP PICTURE:
--
-- users table                          posts table
-- ┌────┬──────────┐                    ┌────┬──────────────────────┬────────┐
-- │ id │ username  │                    │ id │ title                │ user_id│
-- ├────┼──────────┤                    ├────┼──────────────────────┼────────┤
-- │ 1  │ alice    │◄───────────────────│ 1  │ My First Post        │ 1      │
-- │ 2  │ bob      │◄───────────────────│ 2  │ Learning SQLite      │ 1      │
-- └────┴──────────┘                    │ 3  │ Bob's Adventure      │ 2      │
--                                      └────┴──────────────────────┴────────┘
--
-- The user_id column in posts "references" the id column in users.
-- This is called a FOREIGN KEY.
sapphire 
var sql = SQLite();
var db = sql.open(":memory:");

// Create the users table
sql.execute(db, "CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,
    username TEXT NOT NULL,
    email TEXT
)");

// Create the posts table with a FOREIGN KEY
sql.execute(db, "CREATE TABLE IF NOT EXISTS posts (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT,
    user_id INTEGER,
    FOREIGN KEY (user_id) REFERENCES users(id)
)");

// Insert some users
sql.execute(db, "INSERT INTO users (username, email) VALUES ('alice', 'alice@example.com')");
sql.execute(db, "INSERT INTO users (username, email) VALUES ('bob', 'bob@example.com')");

// Insert posts — notice how we link user_id to the user's id
sql.execute(db, "INSERT INTO posts (title, content, user_id) VALUES ('My First Post', 'Hello world!', 1)");
sql.execute(db, "INSERT INTO posts (title, content, user_id) VALUES ('Learning SQLite', 'Databases are fun!', 1)");
sql.execute(db, "INSERT INTO posts (title, content, user_id) VALUES ('Bob''s Adventure', 'Went hiking today.', 2)");

print("Users and posts created with relationships!");
> Users and posts created with relationships!
💡 Note: In the INSERT for Bob's Adventure, we used two single quotes ('') inside the string. In SQL, to include a literal single quote character in a string, you escape it by doubling it: 'Bob''s'.

10. JOINs — Combining Tables

When you have data spread across multiple tables, you use JOIN to combine them in a single query. The most common type is INNER JOIN, which returns only rows that have matching values in both tables.

sapphire 
// INNER JOIN: get posts with their author's username
var postsWithAuthors = sql.query(db, "SELECT
    posts.title,
    posts.content,
    users.username
FROM posts
INNER JOIN users ON posts.user_id = users.id");

print("--- Posts with Authors ---");
for (var row of postsWithAuthors) {
    print("'" + row.title + "' by " + row.username);
    print("  " + row.content);
}
> --- Posts with Authors ---
> 'My First Post' by alice
> Hello world!
> 'Learning SQLite' by alice
> Databases are fun!
> 'Bob's Adventure' by bob
> Went hiking today.
sapphire 
// LEFT JOIN: get ALL users, even if they have no posts
var allUsersWithPosts = sql.query(db, "SELECT
    users.username,
    posts.title
FROM users
LEFT JOIN posts ON users.id = posts.user_id");

print("--- All Users and Their Posts ---");
for (var row of allUsersWithPosts) {
    if (row.title == nil) {
        print(row.username + " has no posts yet.");
    } else {
        print(row.username + " wrote: " + row.title);
    }
}
> --- All Users and Their Posts ---
> alice wrote: My First Post
> alice wrote: Learning SQLite
> bob wrote: Bob's Adventure
💡 JOIN Types:
INNER JOIN — Only rows that match in both tables.
LEFT JOIN — All rows from the left table, plus matching rows from the right table (or NULL if no match).
RIGHT JOIN — Opposite of LEFT JOIN (not directly supported in SQLite, but you can swap the table order).

11. Transactions — Keeping Data Safe

A transaction is a group of operations that must all succeed together. If any one of them fails, all of them are rolled back (undone). This is crucial for data integrity.

Imagine you're building a banking app. Transferring money from Alice to Bob requires two steps: subtract from Alice's account, then add to Bob's account. If your program crashes after the subtraction but before the addition, money would disappear! Transactions prevent this.

sapphire 
var sql = SQLite();
var db = sql.open(":memory:");

sql.execute(db, "CREATE TABLE IF NOT EXISTS accounts (
    id INTEGER PRIMARY KEY,
    name TEXT,
    balance REAL
)");

sql.execute(db, "INSERT INTO accounts VALUES (1, 'Alice', 1000.00)");
sql.execute(db, "INSERT INTO accounts VALUES (2, 'Bob', 500.00)");

print("Before transfer:");
var before = sql.query(db, "SELECT * FROM accounts");
for (var a of before) {
    print("  " + a.name + ": $" + a.balance);
}

// BEGIN TRANSACTION — start the atomic operation
sql.execute(db, "BEGIN TRANSACTION");

// Step 1: Subtract $200 from Alice
sql.execute(db, "UPDATE accounts SET balance = balance - 200 WHERE name = 'Alice'");

// Step 2: Add $200 to Bob
sql.execute(db, "UPDATE accounts SET balance = balance + 200 WHERE name = 'Bob'");

// If both steps worked, COMMIT — save the changes permanently
sql.execute(db, "COMMIT");

print("\nAfter transfer:");
var after = sql.query(db, "SELECT * FROM accounts");
for (var a of after) {
    print("  " + a.name + ": $" + a.balance);
}
> Before transfer:
> Alice: $1000
> Bob: $500
>
> After transfer:
> Alice: $800
> Bob: $700
sapphire 
// Example: ROLLBACK if something goes wrong
sql.execute(db, "BEGIN TRANSACTION");

// Oops — we tried to give more money than exists
sql.execute(db, "UPDATE accounts SET balance = balance - 999999 WHERE name = 'Alice'");

// The balance would go negative. Let's undo it!
sql.execute(db, "ROLLBACK");

// Verify — everything is back to normal
var check = sql.query(db, "SELECT * FROM accounts WHERE name = 'Alice'");
print("Alice's balance after rollback: $" + check[0].balance);
> Alice's balance after rollback: $800

12. Prepared Statements

When you build SQL queries by concatenating strings, you open yourself up to SQL injection attacks — a security vulnerability where a user can trick your database into running malicious commands. For example:

sapphire 
// ❌ DANGEROUS — never do this!
var userInput = "Alice'; DROP TABLE users; --";
sql.execute(db, "SELECT * FROM users WHERE name = '" + userInput + "'");

Prepared statements (also called parameterized queries) solve this by separating the SQL code from the data. You write the SQL with placeholders (?), then provide the values separately. SQLite handles the escaping for you.

sapphire 
// ✅ SAFE — use prepared statements with ? placeholders
var userName = "Alice";
var userAge = 30;

// Execute with parameters
sql.execute(db, "INSERT INTO users (name, age) VALUES (?, ?)", userName, userAge);

// Query with parameters
var results = sql.query(db, "SELECT * FROM users WHERE name = ?", userName);

for (var row of results) {
    print(row.name + " is " + row.age + " years old");
}
> Alice is 30 years old
🔒 Security Best Practice: Always use prepared statements when your SQL query includes data from user input, files, API responses, or any other external source. It's the #1 way to prevent SQL injection attacks.

13. Error Handling

Database operations can fail for many reasons — a table might not exist, you might try to insert duplicate data, or the SQL syntax might be wrong. Always wrap your database code in try/catch blocks.

sapphire 
var sql = SQLite();
var db = sql.open(":memory:");

try {
    // This will fail — the table doesn't exist
    var rows = sql.query(db, "SELECT * FROM nonexistent_table");
    print("Query succeeded.");
} catch (e) {
    print("Error caught: " + e);
}
> Error caught: no such table: nonexistent_table
sapphire 
// A robust pattern: create table, then safely operate
function safeInsertUser(db, sql, name, email) {
    try {
        // Ensure table exists first
        sql.execute(db, "CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY,
            name TEXT,
            email TEXT
        )");

        sql.execute(db, "INSERT INTO users (name, email) VALUES (?, ?)", name, email);
        print("User '" + name + "' inserted successfully!");
        return true;
    } catch (e) {
        print("Failed to insert user: " + e);
        return false;
    }
}

safeInsertUser(db, sql, "Alice", "alice@test.com");

14. Real-World Project Example

Let's build a complete mini inventory system that demonstrates everything we've learned in a practical, real-world scenario.

sapphire 
// =========================================
//  MINI INVENTORY MANAGEMENT SYSTEM
// =========================================

function initDatabase(sql, db) {
    // Create all tables we need
    sql.execute(db, "CREATE TABLE IF NOT EXISTS categories (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL UNIQUE
    )");

    sql.execute(db, "CREATE TABLE IF NOT EXISTS products (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL,
        price REAL NOT NULL,
        stock INTEGER NOT NULL DEFAULT 0,
        category_id INTEGER,
        FOREIGN KEY (category_id) REFERENCES categories(id)
    )");

    sql.execute(db, "CREATE TABLE IF NOT EXISTS sales (
        id INTEGER PRIMARY KEY,
        product_id INTEGER NOT NULL,
        quantity INTEGER NOT NULL,
        total_price REAL NOT NULL,
        sale_date TEXT NOT NULL,
        FOREIGN KEY (product_id) REFERENCES products(id)
    )");
}

function addCategory(sql, db, name) {
    try {
        sql.execute(db, "INSERT INTO categories (name) VALUES (?)", name);
        print("Category '" + name + "' added.");
    } catch (e) {
        print("Category '" + name + "' already exists.");
    }
}

function addProduct(sql, db, name, price, stock, categoryName) {
    // Get the category ID
    var cat = sql.query(db, "SELECT id FROM categories WHERE name = ?", categoryName);
    if (cat == nil || len(cat) == 0) {
        print("Category '" + categoryName + "' not found!");
        return;
    }

    sql.execute(db, "INSERT INTO products (name, price, stock, category_id) VALUES (?, ?, ?, ?)",
        name, price, stock, cat[0].id);
    print("Product '" + name + "' added.");
}

function recordSale(sql, db, productName, quantity) {
    try {
        // Start a transaction
        sql.execute(db, "BEGIN TRANSACTION");

        // Get the product
        var prod = sql.query(db, "SELECT * FROM products WHERE name = ?", productName);
        if (prod == nil || len(prod) == 0) {
            print("Product '" + productName + "' not found!");
            sql.execute(db, "ROLLBACK");
            return;
        }

        var product = prod[0];
        if (product.stock < quantity) {
            print("Not enough stock! Only " + product.stock + " available.");
            sql.execute(db, "ROLLBACK");
            return;
        }

        // Calculate total price
        var total = product.price * quantity;

        // Update stock
        sql.execute(db, "UPDATE products SET stock = stock - ? WHERE id = ?",
            quantity, product.id);

        // Record the sale
        var today = "2024-07-16";
        sql.execute(db, "INSERT INTO sales (product_id, quantity, total_price, sale_date) VALUES (?, ?, ?, ?)",
            product.id, quantity, total, today);

        // All good — commit
        sql.execute(db, "COMMIT");
        print("Sale recorded: " + quantity + " x " + productName + " = $" + total);

    } catch (e) {
        sql.execute(db, "ROLLBACK");
        print("Sale failed: " + e);
    }
}

function showInventoryReport(sql, db) {
    print("\n========== INVENTORY REPORT ==========");

    // JOIN to show products with their categories
    var products = sql.query(db, "SELECT
        p.id, p.name, p.price, p.stock, c.name as category
    FROM products p
    INNER JOIN categories c ON p.category_id = c.id
    ORDER BY c.name, p.name");

    var totalValue = 0.0;
    for (var p of products) {
        var value = p.price * p.stock;
        totalValue = totalValue + value;
        print(p.category + " | " + p.name + " | $" + p.price + " | Stock: " + p.stock + " | Value: $" + value);
    }

    print("\nTotal inventory value: $" + totalValue);

    // Show recent sales
    print("\n--- Recent Sales ---");
    var sales = sql.query(db, "SELECT
        s.quantity, s.total_price, s.sale_date, p.name as product
    FROM sales s
    INNER JOIN products p ON s.product_id = p.id
    ORDER BY s.id DESC
    LIMIT 5");

    for (var s of sales) {
        print(s.sale_date + " | " + s.product + " x" + s.quantity + " = $" + s.total_price);
    }
}

15. Complete API Reference

Here is every method available in the Sapphire SQLite module, with full descriptions.

15.1 SQLite()

Creates a new SQLite handler instance. You must call this before any other SQLite operations. You can create multiple instances to work with multiple databases simultaneously.

sapphire 
var sql = SQLite();
var sql2 = SQLite();  // A second, independent instance

15.2 sql.open(filename)

Opens a connection to a database file. If the file doesn't exist, it is created automatically. Returns a database handle (integer) on success, or -1 on failure.

ParameterTypeDescription
filenameStringPath to the .db file, or ":memory:" for RAM-only
sapphire 
var db = sql.open("data.db");
if (db == -1) {
    print("Failed to open database!");
}

15.3 sql.execute(db, sql, ...params)

Executes a SQL statement that does not return rows (e.g., CREATE TABLE, INSERT, UPDATE, DELETE). Returns the result code.

ParameterTypeDescription
dbIntegerThe database handle from open()
sqlStringThe SQL statement to execute
...paramsAny (optional)Values for ? placeholders (prepared statements)
sapphire 
// Without parameters
sql.execute(db, "CREATE TABLE IF NOT EXISTS test (id INTEGER)");

// With parameters (prepared statement)
sql.execute(db, "INSERT INTO test VALUES (?)", 42);

15.4 sql.execute(sql, ...params) (object-style)

If you used the object-style API (called open() without capturing the return value), you can call execute directly on the SQLite object. It uses the internally stored database handle.

sapphire 
var sqlite = SQLite();
sqlite.open(":memory:");
sqlite.execute("CREATE TABLE test (id INTEGER)");

15.5 sql.query(db, sql, ...params)

Executes a SQL statement that returns rows (typically SELECT). Returns an array of maps, where each map represents a row with column names as keys. Returns nil on failure.

ParameterTypeDescription
dbIntegerThe database handle from open()
sqlStringThe SQL SELECT statement to execute
...paramsAny (optional)Values for ? placeholders
sapphire 
// Without parameters
var all = sql.query(db, "SELECT * FROM users");

// With parameters
var filtered = sql.query(db, "SELECT * FROM users WHERE age > ?", 18);

// Access row data
for (var row of filtered) {
    print(row.name + " is " + row.age);
}

15.6 sql.query(sql, ...params) (object-style)

Object-style version of query that uses the internally stored database handle.

sapphire 
var sqlite = SQLite();
sqlite.open(":memory:");
sqlite.execute("CREATE TABLE t (v INTEGER)");
sqlite.execute("INSERT INTO t VALUES (1), (2), (3)");
var rows = sqlite.query("SELECT * FROM t");
print("Row count: " + len(rows));
> Row count: 3

15.7 sql.close(db)

Closes the database connection. Always call this when you're done to free system resources and ensure all data is written to disk.

sapphire 
sql.close(db);
print("Database connection closed.");
> Database connection closed.
