SQLite Database

Sapphire comes with a native, built-in SQLite3 engine. You can create local, serverless databases without installing any external database management system.

Creating and Connecting

You interact with SQLite by initializing the SQLite object and opening a file. If the file doesn't exist, it will be automatically created.

sapphire 
var db = SQLite.open("test.db");
print("Database connected successfully!");

Executing Queries

To run SQL statements like CREATE TABLE, INSERT, UPDATE, or DELETE, use the execute method.

sapphire 
var db = SQLite.open("test.db");
db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)");
db.execute("INSERT INTO users (name) VALUES ('Sapphire')");
print("Record inserted!");

Fetching Data

To retrieve data, use the query method. It returns an array of maps, where each map represents a row from the database.

sapphire 
var db = SQLite.open("test.db");
var rows = db.query("SELECT * FROM users");

for (var row of rows) {
    print("User ID: " + row.id + " Name: " + row.name);
}
