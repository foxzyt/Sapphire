Data Structures

Storing multiple pieces of data efficiently is a core requirement for any serious application. Sapphire provides two highly optimized, built-in data structures that handle memory allocation dynamically: Lists and Maps.

Working with Lists (Dynamic Arrays)

A List in Sapphire is a dynamic array that can hold items of any type simultaneously. You can create one using the literal syntax [item1, item2, ...] or the listCreate() function.

sapphire 
// Create a list using literal syntax (recommended)
var fruits = ["Apple", "Banana", "Cherry"];

// Create an empty list using listCreate()
var inventory = listCreate();

// Add items with listAppend
listAppend(inventory, "Sword");
listAppend(inventory, "Shield");
listAppend(inventory, 99);  // You can mix strings and numbers!

print("Total items: " + listLength(inventory));
> Total items: 3

Accessing and Modifying Elements

You can access elements within a list using zero-based indexing brackets [index]. Index 0 is the first element, index 1 is the second, and so on. You can also reassign values at specific indices directly.

sapphire 
var items = ["Map", "Compass", "Key"];

// Access by index (0-based)
var firstItem = items[0];
print("First item: " + firstItem);

// Modify an element
items[0] = "Treasure Map";
print("Updated first item: " + items[0]);

// Get the length
print("List has " + len(items) + " items");
> First item: Map
> Updated first item: Treasure Map
> List has 3 items

Iterating Over Lists

You can loop through list elements using for...of (to get values) or for...in (to get indices).

sapphire 
var scores = [95, 82, 73, 91];

// for...of gives you the values
print("Scores:");
for (var score of scores) {
    print("  - " + score);
}

// for...in gives you the indices (0, 1, 2, ...)
print("Index 2: " + scores[2]);
> Scores:
> - 95
> - 82
> - 73
> - 91
> Index 2: 73

Spread Operator & Destructuring

In v1.0.9, Sapphire introduced the spread operator (...) to easily expand elements from one list into another, and destructuring syntax to extract list values directly into variables.

sapphire 
// Spread operator — expand one list into another
var baseItems = ["Map", "Compass"];
var allItems = [...baseItems, "Key", "Torch"];
print("All items: " + allItems);

// Destructuring — extract values into variables
var [item1, item2] = allItems;
print("First item: " + item1);
print("Second item: " + item2);
> All items: [Map, Compass, Key, Torch]
> First item: Map
> Second item: Compass

Working with Maps (Dictionaries)

Maps (also known as Dictionaries or Hash Tables) allow you to store Key-Value pairs. They are perfect for grouping related properties together, like representing a user or a configuration object.

sapphire 
// Create a Map using curly braces syntax
var player = {
    "name": "Foxzyt",
    "level": 42,
    "isOnline": true
};

// Retrieve values via bracket notation
print("Player Name: " + player["name"]);

// Set new values via bracket notation
player["level"] = 43;
print("Player Level: " + player["level"]);

// Add new keys dynamically
player["class"] = "Warrior";
print("Player Class: " + player["class"]);
> Player Name: Foxzyt
> Player Level: 43
> Player Class: Warrior

Iterating Over Maps

You can loop through map keys using for...in and access the corresponding values inside the loop.

sapphire 
var config = {
    "theme": "dark",
    "volume": 80,
    "fullscreen": true
};

// Loop through all keys
for (var key in config) {
    print(key + " = " + config[key]);
}
> theme = dark
> volume = 80
> fullscreen = true

Shorthand Properties

If you are assigning variables to a map where the key name matches the variable name, you can use the shorthand syntax (introduced in v1.0.9) to keep your code clean.

sapphire 
var theme = "dark";
var fontSize = 14;

// Shorthand syntax — no need to write { "theme": theme, "fontSize": fontSize }
var config = { theme, fontSize };
print(config["theme"]);     // Prints: dark
print(config["fontSize"]);  // Prints: 14
> dark
> 14

Nested Structures

You can nest lists inside maps and maps inside lists to create complex data structures.

sapphire 
// A list of maps — perfect for tabular data
var users = [
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25},
    {"name": "Carol", "age": 28}
];

// Access nested data
print("Second user: " + users[1]["name"]);

// Loop through the list and access map properties
for (var user of users) {
    print(user["name"] + " is " + user["age"] + " years old");
}
> Second user: Bob
> Alice is 30 years old
> Bob is 25 years old
> Carol is 28 years old
