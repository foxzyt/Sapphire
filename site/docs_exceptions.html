Exceptions Handling

Errors happen. The network might drop, a file might be missing, or a user might enter invalid input. If left unhandled, an error crashes the Sapphire Virtual Machine. To build resilient applications, you must use Exception Handling.

Try and Catch

The try / catch block allows you to "attempt" to run dangerous code. If that code throws an error, the VM immediately aborts the try block and jumps into the catch block without crashing the entire program.

sapphire 
try {
    print("Attempting risky operation...");
    // Attempting to divide by zero!
    var badMath = 100 / 0;
    print("This line will never run.");
} catch (e) {
    print("Caught an error! " + e);
}

print("Program continues normally.");
> Attempting risky operation...
> Caught an error! Division by zero.
> Program continues normally.

Throwing Custom Exceptions

You are not limited to catching VM errors. You can also throw your own custom errors using the throw keyword. This is extremely useful for input validation in functions.

sapphire 
function setAge(age) {
    if (age < 0) {
        throw "Age cannot be negative!";
    }
    print("Age set to: " + age);
}

try {
    setAge(-5);
} catch (err) {
    print("Validation Failed: " + err);
}
> Validation Failed: Age cannot be negative!

Using Finally

Sometimes you need to ensure that certain cleanup code runs whether an error occurred or not (e.g., closing an open file or a network socket). The finally block executes after try and catch, regardless of the outcome.

sapphire 
try {
    print("Opening Database Connection...");
    throw "Database Timeout!";
} catch (e) {
    print("Error: " + e);
} finally {
    print("Closing Database Connection. Cleanup complete.");
}
> Opening Database Connection...
> Error: Database Timeout!
> Closing Database Connection. Cleanup complete.
