Control Flow & Functions

Code that just executes line-by-line from top to bottom is rarely enough for complex applications. You need the ability to make decisions and repeat actions. Sapphire provides classic C-style control flow statements to branch your code's execution paths.

If / Else Conditions

The if statement allows you to execute a block of code only if a specific condition evaluates to true. You can chain conditions using else if and provide a fallback using else.

sapphire 
var temperature = 25;

if (temperature > 30) {
    print("It's really hot outside!");
} else if (temperature > 20) {
    print("The weather is perfect.");
} else {
    print("It's getting chilly.");
}
> The weather is perfect.

While Loops

To execute a block of code repeatedly as long as a condition remains true, use a while loop. Be careful to eventually make the condition false, or you will create an infinite loop!

sapphire 
var count = 3;

print("Liftoff countdown:");
while (count > 0) {
    print(count);
    count = count - 1;
}
print("Blastoff! 🚀");
> Liftoff countdown:
> 3
> 2
> 1
> Blastoff! 🚀

Switch / Case

When you have a variable that can take many specific values, a switch statement is much cleaner than writing a long chain of else if checks. It compares a variable against multiple case values.

sapphire 
var status = "success";

switch (status) {
    case "success":
        print("Operation completed successfully.");
    case "error":
        print("A critical error occurred!");
    default:
        print("Unknown status code.");
}
> Operation completed successfully.

Iterators (for...in, for...of, foreach)

Sapphire supports elegant iteration over arrays, maps, and strings using for in, for of, and foreach.

sapphire 
var fruits = ["Apple", "Banana", "Cherry"];

// 'for of' gives you the values
for (var fruit of fruits) {
    print("Value: " + fruit);
}

// 'foreach' is an alias for 'for of'
foreach (var fruit in fruits) {
    print("Foreach: " + fruit);
}

// 'for in' gives you the keys or indices
for (var index in fruits) {
    print("Index: " + index + " is " + fruits[index]);
}

Functions

Functions are reusable blocks of code. You define them using the function keyword. They can accept inputs (parameters) and optionally return an output value using the return keyword.

sapphire 
// Defining a function that takes two parameters
function multiply(a, b) {
    var res = a * b;
    return res;
}

// Calling the function and storing the result
var answer = multiply(5, 4);
print("5 times 4 is: " + answer);
> 5 times 4 is: 20

Arrow Functions

For short, concise operations, you can use arrow functions (added in v1.0.9). They are great for passing callbacks or saving space.

sapphire 
// A concise arrow function
var square = (x) => x * x;
print("Square of 6 is: " + square(6));

// With multiple parameters
var add = (a, b) => a + b;
print("10 + 20 is: " + add(10, 20));

Recursive Functions

Because Sapphire has a robust call stack, functions can safely call themselves. This is known as recursion and is heavily used in advanced algorithmic logic.

sapphire 
function factorial(n) {
    if (n == 0) {
        return 1;
    }
    return n * factorial(n - 1);
}

print("Factorial of 5: " + factorial(5));
> Factorial of 5: 120
